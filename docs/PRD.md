# 📄 제품 요구사항 정의서 (PRD): 마이링크(My Link)

## 1. 프로젝트 개요
- **프로젝트명:** 마이링크 (My Link)
- **목적:** 다양한 소셜 미디어 플랫폼과 웹페이지, 포트폴리오 링크를 단일 페이지로 수집하여 공유할 수 있도록 지원하는 '멀티 링크 프로필' 서비스
- **대상 사용자 핵심 타겟:** **개발자 및 크리에이터**
  - 여러 소셜 채널과 포트폴리오, 작업물을 하나의 링크로 통합하고자 하는 IT 개발자 및 콘텐츠 크리에이터
  - 심플하면서도 확장성 있는 개인 프로필 페이지가 필요한 사람

## 2. 핵심 기능 목록

### 2.1. 필수 기능 (MVP - Minimum Viable Product)
| 분류 | 기능명 | 설명 |
|---|---|---|
| **계정** | 구글 소셜 로그인 | **Firebase Authentication**을 이용한 구글 소셜 로그인 (단일 인증 방식) |
| **프로필** | 기본 프로필 설정 | 프로필 이미지, 사용자 이름(ID), 별명, 짧은 소개글 등록 및 수정 |
| **링크** | 링크 관리 (CRUD) | 새로운 링크(URL, 제목) 추가, 수정, 삭제 기능 |
| **링크** | 링크 순서 변경 | Drag & Drop을 이용한 등록 링크 노출 순서 변경 기능 |
| **링크** | 링크 활성화 토글 | 삭제하지 않고 특정 링크의 노출 여부를 On/Off 하는 임시 숨김 기능 |
| **디자인**| shadcn/ui 기반 테마 지원 | **shadcn/ui** 컴포넌트를 활용한 깔끔하고 일관성 있는 디자인 테마 제공 |
| **공유** | 고유 프로필 URL 생성 | `mylink.com/@username` 형식의 퍼블릭 링크 생성 및 접속 지원 |

### 2.2. 향후 구현 기능 (V2 및 고도화 대상)
| 분류 | 기능명 | 설명 |
|---|---|---|
| **통계** | 방문자 대시보드 | 페이지 총 방문자 수 및 개별 링크 클릭 수 통계 제공 (추후 구현 예정) |
| **디자인**| 커스텀 디자인 옵션 | 사용자가 직접 커스텀 배경 이미지 적용, 버튼 모양 다각화, 폰트 세부 설정 가능 |
| **연동** | 미디어 및 포트폴리오 임베드 | 유튜브 영상, 깃허브(GitHub) 레포지토리 등 외부 플랫폼의 정보를 페이지 내 직접 노출 |
| **부가** | 커스텀 도메인 연결 | 기본 제공 URL 대신 사용자가 소유한 개인 도메인 주소를 연결할 수 있는 기능 |

## 3. 각 기능의 상세 설명 및 기술 요구사항

- **인증 시스템:** 이메일 가입이나 다른 SNS 로그인 없이 **오직 Firebase를 통한 구글 로그인 하나로만 제한**하여 가입 절차를 극도로 간소화합니다. 
- **사용자 프로필 시스템:** 사용자 ID(`username`)는 고유 접속 URL로 활용되므로 중복될 수 없어야 하며, 영문과 숫자 등으로 제약 조건을 두어야 합니다.
- **디자인 시스템 (shadcn/ui):** shadcn/ui의 컴포넌트들을 적극 활용하여, 현대적이고 접근성 높은 인터페이스를 빠르게 구축합니다. 개발자 친화적인 깔끔한 UI/UX를 지향합니다.
- **링크 관리 경험 (대시보드):** 사용자가 링크를 관리하는 영역은 가장 빈번하게 이용되므로, 링크 수정이나 순서 이동(Drag & Drop) 시 새로고침 없이 즉각적으로 반영되어야 합니다.
- **방문자 뷰어 (퍼블릭 페이지):** 실제 사용자들에게 공유되는 페이지로, 모바일 환경을 최우선으로 고려한 렌더링 속도 최적화가 필수적입니다.
