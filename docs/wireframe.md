# 📐 마이링크(My Link) 화면 구조 와이어프레임 (Wireframe)

이 문서는 마이링크 서비스의 주요 화면 레이아웃과 진입점(Entry Points)을 정의합니다. 대상 사용자인 크리에이터와 방문자 모두 스마트폰 접속 비율이 압도적으로 높으므로, **모바일 우선(Mobile First)** UI를 기본 뷰포트로 설계합니다.

---

## 1. 퍼블릭 프로필 페이지 (방문자 화면)
방문자가 고유 주소(`mylink.com/@username`)로 접속했을 때 보여지는 화면입니다. 불필요한 장식을 배제하고 핵심 콘텐츠(링크)로 즉시 시선이 가도록 유도합니다.

```text
[ 모바일 세로 화면 기준 ]

+--------------------------------------------------+
|                                  [공유하기 아이콘] |
+--------------------------------------------------+
|                                                  |
|                   [프로필 이미지]                  |
|                                                  |
|                @username (사용자 아이디)           |
|            "여기에 1~2줄 분량의 소개글이 표시됩니다."  |
|                                                  |
|    (SNS) [GitHub] [Velog] [Instagram] [Email]    |
|                                                  |
+--------------------------------------------------+
|                                                  |
| [   최신 포트폴리오 노션 링크 가기 (새 탭)  [↗]  ] |
|                                                  |
+--------------------------------------------------+
|                                                  |
| [   오픈소스 컨트리뷰트 레포지토리 (새 탭)  [↗]  ] |
|                                                  |
+--------------------------------------------------+
|                                                  |
| [      최근 작성한 기술 블로그 글 (새 탭)   [↗]  ] |
|                                                  |
+--------------------------------------------------+
|                                                  |
|                Powered by My Link                |
+--------------------------------------------------+
```

---

## 2. 관리자 대시보드 (소유자 화면)
소유자가 로그인 후 진입하는 메인 관리 화면입니다. 링크를 순서대로 관리하고 즉각적으로 토글할 수 있는 뛰어난 사용성에 초점을 맞춥니다.

### 2.1 메인 대시보드 리스트
```text
+--------------------------------------------------+
| ≡ (메뉴)   내 링크 | 디자인(테마)      [로그아웃]  |
+--------------------------------------------------+
|                                                  |
|              [ ➕ 새로운 링크 추가하기 ]           |
|                                                  |
+--------------------------------------------------+
| [=] (드래그하여 순서 변경)                          |
|                                                  |
|   제목 : 최신 포트폴리오 노션 링크 가기              |
|   URL  : https://notion.so/my-portfolio...       |
|                                                  |
|   [✏️수정]  [🗑️삭제]            [활성화 On 🟢] (토글)|
+--------------------------------------------------+
| [=] (드래그하여 순서 변경)                          |
|                                                  |
|   제목 : 마감된 지난 시즌 토이프로젝트               |
|   URL  : https://github.com/...                  |
|                                                  |
|   [✏️수정]  [🗑️삭제]            [숨김 Off ⚪] (토글)|
+--------------------------------------------------+
```

### 2.2 '링크 추가' 또는 '수정' 모달 팝업 상태
링크 추가 버튼 또는 수정 탭을 클릭했을 때 나타나는 바텀 시트(Bottom Sheet) 형태의 입력창입니다.
```text
+--------------------------------------------------+
|                                                  |
|  [ 📌 링크 추가하기 ]                    [ X 닫기 ]|
|  ----------------------------------------------  |
|                                                  |
|  목적지 URL                                       |
|  [ https://.... 주소를 붙여넣으세요             ] |
|                                                  |
|  링크 타이틀                                       |
|  [ 방문자가 확인하게 될 제목을 적어주세요....... ] |
|                                                  |
|                                                  |
|              [ 취소 ]       [ ✔️ 저장하기 ]      |
|                                                  |
+--------------------------------------------------+
```
