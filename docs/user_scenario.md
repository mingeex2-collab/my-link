# 🗺️ 마이링크(My Link) 사용자 시나리오 (User Scenario)

## 1. 방문자 (Visitor): 마이링크 페이지 방문 및 이용 과정

* **사용자는** 크리에이터의 전체 작업물과 채널을 한눈에 파악**하기 위해** 공유받은 마이링크 URL(`mylink.com/@username`)에 접속**한다.**
* **사용자는** 페이지 주인이 누구인지 식별**하기 위해** 최상단에 위치한 프로필 이미지와 소개글을 확인**한다.**
* **사용자는** 외부 사이트를 확인하는 동안 기존 마이링크 페이지 탐색 흐름을 잃지 않게 **하기 위해** 본문에 나열된 링크 블록을 클릭하여 **'새 창(새 탭)'으로 열어 이동**한다.
* **사용자는** 마음에 드는 크리에이터의 프로필을 친구들이나 타 플랫폼에 추천**하기 위해** 화면의 '공유하기' 아이콘을 클릭하여 URL을 클립보드에 복사**한다.**

## 2. 소유자 (Owner): 링크 관리 과정 (추가/수정/삭제/순서변경/숨김)

### [링크 추가]
* **사용자는** 방문자에게 공유할 새로운 목적지를 등록**하기 위해** 관리자 대시보드에서 '새 링크 추가' 버튼을 클릭**한다.**
* **사용자는** 새로 추가된 항목에 올바른 주소가 연결되게 **하기 위해** URL 입력창에 목적지 웹주소를 붙여넣거나 입력**한다.**
* **사용자는** 방문자가 해당 링크가 무엇인지 직관적으로 이해할 수 있게 **하기 위해** 링크의 제목(Title)을 입력하고 '저장(또는 완료)' 버튼을 클릭**한다.**

### [링크 수정]
* **사용자는** 등록되어 있는 기존 링크의 주소나 오타를 변경**하기 위해** 대시보드 리스트에서 해당 링크 블록의 '수정하기' 아이콘(또는 영역)을 클릭**한다.**
* **사용자는** 갱신된 정보를 페이지에 반영**하기 위해** 활성화된 입력창에서 텍스트를 수정한 뒤 '저장'을 클릭**한다.**

### [링크 삭제]
* **사용자는** 더 이상 사용하지 않거나 만료된 링크를 페이지에서 완전히 제거**하기 위해** 해당 링크 블록의 '삭제' 아이콘(휴지통 모양 등)을 클릭**한다.**
* **사용자는** 실수로 중요한 링크가 영구 삭제되는 것을 방지**하기 위해** 화면에 나타난 재확인 컨펌 팝업에서 '최종 삭제'를 클릭**한다.**

### [링크 순서 변경]
* **사용자는** 더 중요하거나 최근에 작성된 링크를 방문자에게 우선적으로 노출**하기 위해** 해당 링크 블록을 마우스(또는 터치)로 '드래그 앤 드롭'하여 원하는 위치로 이동**시킨다.**

### [링크 표시 상태 토글 (숨김/활성화)]
* **사용자는** 시즌성 링크 등 나중에 다시 쓸 링크를 굳이 삭제하지 않고 방문자 화면에서만 지우게 **하기 위해** 해당 링크 블록의 '상태 스위치(토글 버튼)'를 클릭하여 Off(숨김) 상태로 변경**한다.**
